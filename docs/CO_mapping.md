# Course Outcomes Mapping (CO-1 to CO-6)
- CO-1: System architecture, Makefile automation, compilation lifecycle.
- CO-2: Process management (fork, exec, waitpid, signal dispatch) & scheduler.
- CO-3: Inter-Process Communication (pipes, FIFOs, signals).
- CO-4: Memory management (/proc inspection, POSIX shared memory shm_open/mmap).
- CO-5: Virtual Filesystem (/proc, file descriptors, inode inspection).
- CO-6: Concurrency and Thread Pools (POSIX pthreads, semaphores, mutexes).
